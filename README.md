# React + Vite

## Установка и запуск проекта

Для того чтобы начать работу с проектом, необходимо установить зависимости:

```bash
npm install
```

Запуск проекта в режиме разработчика (dev режиме):

```bash
npm run dev
```

Для сборки проекта в build версию (для продакшена) используйте команду:

```bash
npm run build
```
